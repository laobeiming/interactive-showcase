# 待机背景视频目录

将展厅待机视频放入本目录，程序启动时会自动查找并**全屏循环播放**。

## 命名与格式
- 支持格式：`.mp4`、`.mov`、`.mkv`、`.avi`、`.wmv`、`.webm`、`.m4v`
- 推荐命名：`standby.mp4`
- 程序优先选择文件名包含 `standby`、`idle`、`waiting`、`daiji`、`待机` 的视频；没有匹配项时使用目录中排序第一的视频。
- 也可以通过命令行指定：`python main.py --video "D:\video\standby.mp4"`

## 编码建议
- 视频编码：H.264（AVC），像素格式 `yuv420p`
- 分辨率：1920×1080，帧率 30fps
- 待机视频默认静音播放（可用 `--volume 0~100` 调整音量）

## 兜底机制
目录中没有可用视频、视频文件损坏或解码失败时，程序会自动切换到
**纯黑背景 + 呼吸文字** 的内置待机页，保证展厅大屏始终有画面提示。

> GitHub 单文件大小限制为 100MB，较大的视频建议使用 Git LFS 或仅保存在展厅本地机器。
